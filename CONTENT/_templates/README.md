# Template Konten

Folder ini berisi contoh siap salin. Template **tidak dipakai langsung** oleh website, jadi aman diedit atau dihapus.

| Template | Dipakai untuk |
|---|---|
| `template-leadership.ts` | Menambah pengurus di `02-LEADERSHIP/team.ts` |
| `template-article-entry.ts` | Menambah informasi artikel di `03-ARTICLES/articles.ts` |
| `template-article.md` | Menulis isi artikel di `03-ARTICLES/posts/` |
| `template-gallery.ts` | Menambah album/foto di `04-GALLERY/gallery.ts` |
| `template-event.ts` | Menambah kegiatan di `05-EVENTS/events.ts` |
| `template-program.ts` | Menambah program di `06-PROGRAMS/programs.ts` |
| `template-testimonial.ts` | Menambah testimoni di `07-TESTIMONIALS/testimonials.ts` |

Langkah lengkap setiap kategori ada di `CONTENT-GUIDE.md` pada folder utama proyek.
